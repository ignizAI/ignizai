# source/

Brand and design files kept with the website code. **Not deployed** (excluded in `.vercelignore`).

- `logo/` — Igniz AI logo set (mark, lockups, app icon) as SVG + PNG, plus early concepts
- `brand/` — master logo artwork (silver flame, wordmark, full logo files)
- `images/` — original hero / UAE / blog images used in earlier designs
- `legacy/` — scripts and logo from the previous site version (no longer loaded by any page)

The live site is the HTML files in the repo root plus `assets/`.
